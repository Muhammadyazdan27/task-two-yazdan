# task-two-yazdan

# Full Stack System - Backend API

# Description
A robust Node.js and Express RESTful API representing the "brain" of the application. It features GET and POST endpoints and implements the 'Gatekeeper Rule' for strict syntactic and semantic data validation using JSON.

# How to Run
1. Open the terminal inside the project folder.
2. Run `npm install express` to install dependencies.
3. Run `node server.js` to start the backend on `http://localhost:3000`.
4. Use Thunder Client or Postman to test the endpoints.
